# Object Types / Data types

- Number  : 1234 ,3.14 ,2 + 3j ,fraction() ,etc

- String : 'rock' , "bankai" ,etc

- List : [ 2 ,[ 4 ,"five" ] ] , list( range( 10 ) ),etc

- Tuple : (2 , ( 4 ,"five" ) ,"bankai" ) ,etc

- Tuple => () , List => [] , Dictionary => {}

- Tuple => Immutable , List => Mutable , Dictionary => key value pairs

- Dictionary : {'food' = 'samosa', 'bankai' = 'tensa zangetsu'}

- Set : set('abc') , {'a', 'b' , 'c'}

- Set => stores only the unique value   
Ex :if a,b,b,b,c,c,a,c,b => a,b,c

- File : open(file.txt) , open(c:address)

- Boolean : True ,False

- None : No Value Recieved ,Empty

- Functions , Modules , Classes

- Advance : Decoraters , Generators ,Iterater, Meta-programming,etc
